A separate `src/edge_return.cjs` module is implemented with pure `selectEdgeReturn` and bounded `performEdgeReturn`. Selection demands client onGround, integer floor y, original 3–8 supported probes, FULL target block, known collision shapes, every 0.07m intermediate 0.6m AABB body clearance, no unknown/door/hazard or overlapping entities, support contact never decreasing and reaching 9/9. It produces an explicit **nonpermitted candidate**. Its optional physical executor checks a caller-supplied safety callback before every input and rechecks the original geometry plus current support, limits at most six short pulses, releases forward input in every exit, and always reports **serverMovementVerified=false**. Only a separate existing BDS lifecycle may ever settle the outcome; no local result completes a movement.

This initial commit is staging only: no runtime import, no new autonomous behavior, no Mint sync/restart, no game command. Tests simulate both safe edge and reject all unknown/hazard/obstacle/ungrounded/occupied variants, no permission or BDS claims. Runtime integration requires a separate review and all existing STOP/FOLLOW/combat, life/owner, fresh independent BDS double witness and endpoint validation; no automatic retries.
