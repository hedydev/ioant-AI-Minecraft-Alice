## LAN access and privacy

This dashboard has **no username, password, or token** by the user's explicit choice. Any client that can reach the Mac's TCP port `8788` can view and download Alice's logs, potentially including player chats, location coordinates, or other sensitive lines. Binding to `0.0.0.0` includes all relevant Mac IPv4 interfaces, **not only trusted Wi-Fi/LAN** (for example, reachable VPN interfaces). Keep it on trusted networks, do not forward this port on the router, and consider a macOS firewall policy if other networks can reach the Mac. The LAN-facing dashboard remains read-only for all non-Mac clients: the Nginx ACL blocks settings writes outside Mac loopback. The three bounded settings can be edited on Mac localhost, but the dashboard cannot run game commands or write Minecraft worlds. To see the Mac's Wi-Fi LAN address run `ipconfig getifaddr en0`; the startup script also prints that address when available. Nginx changes require stopping and restarting the dashboard script.
